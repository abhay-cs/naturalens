# NaturaLens — Model Training

Training scripts, configs, and notebooks for wildlife recognition models.

**Status:** Not started.

## What goes here

- Training scripts (PyTorch / TensorFlow)
- Hyperparameter configs
- Jupyter notebooks for experimentation
- Data augmentation pipelines

## Notes

- Raw training data is NOT stored in this repo. Use cloud storage (S3, GCS) or DVC.
- Trained model weights are NOT committed to git. Store in a model registry or cloud bucket.
